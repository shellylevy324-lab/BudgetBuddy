After replacement:
1. Open GitHub Desktop.
2. Commit the changes with: Add Build the Amount skill v3.1.0
3. Push origin.
4. Wait for GitHub Pages to finish deploying.
5. Refresh Teacher Center with Ctrl+F5.

7. Open the student's Training Station and test the activity.

LEVELS
Level 1 — Build a named amount using coins.
Level 2 — Make the exact amount shown on a price tag.
Level 3 — Pay with the next whole dollar up.
Level 4 — Create the correct change after paying.
