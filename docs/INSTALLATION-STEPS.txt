BUDDY SKILLS v2.1.0 - REPORTING INFRASTRUCTURE

1. In Supabase, open SQL Editor.
2. Create a new query and paste the full contents of:
   SUPABASE-v2.1.0-REPORTING.sql
3. Run the query. It creates teacher-owned student_sessions and student_trials tables, indexes, validation triggers, RLS policies, and an export view.
4. In your BuddySkillsPlatform project folder, replace:
   - teacher-center.html
   - teacher-center.js
   - platform.css
5. Add the new file:
   - reports.js
6. Keep reports.js in the same folder as teacher-center.js and teacher-center.html.
7. Commit and push the changes to GitHub Pages.
8. Hard-refresh Teacher Center (Ctrl+Shift+R on Windows or Cmd+Shift+R on Mac).
9. Open Reports. A clean empty report should load without a database error.

IMPORTANT
- This package creates and reads the reporting infrastructure.
- Budget Buddy does not write new sessions into these tables yet. That is the next connection step.
- Continue using de-identified pilot student information until your school approves storage of real student data.
